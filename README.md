# Our Lady of Assumption Church — Ramadurgam

A responsive React + Vite website for Our Lady of Assumption Church in Ramadurgam, Andhra Pradesh.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Content notes

- Historical details are adapted from the former public parish website: https://ramadurgam.weebly.com/
- The archived site lists 1850 as the parish established year and Mass times of 6:30 AM Monday–Saturday and 8:00 AM Sunday. Current timings have not been independently verified.
- Contact phone numbers differ across sections of the archived site, so this version avoids presenting either as confirmed.
- Original church and village photographs remain linked through the archived gallery. The homepage hero uses a CSS illustration, not a photograph of the actual church.
